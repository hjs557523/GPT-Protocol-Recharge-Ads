## Engineering Highlights

Not a toy script — a complete, actively maintained engineering project:

- 🔗 **Eight-node orchestration**: checkout → taxes → elements → token → confirm → payment → verify → cancel, with per-node state tracking and failure recovery
- 🧬 **Device fingerprint system**: per-account device identity, persisted profiles, consistent behavior across recharges
- 🌏 **Multi-region profiles**: request headers, language and timezone adapt to the billing region automatically
- 🔁 **Dual payment routes**: automatically detects the order route — both the OpenAI native route and the Stripe hosted route are supported
- 🖥 **One-command CLI**: `protocol/` core + `recharge-flow.cjs` orchestration, run the whole flow from the command line
